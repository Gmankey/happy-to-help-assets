# HAPPY TO HELP — Enhanced Edition v1.0.1
**An interactive story you play through a conversation.**

## Ready to play?
1. Download **[HAPPY_TO_HELP_ENHANCED_v1.0.1_PLAY.md](HAPPY_TO_HELP_ENHANCED_v1.0.1_PLAY.md)**. On GitHub, select **Download raw file** rather than reading the source preview.
2. Open a **fresh ChatGPT conversation** and attach the file.
3. Send: **Read and execute.**
4. Follow the opening instructions.

No separate game website, software installation, coding setup, or API key is required. Where supported by the ChatGPT client, the Enhanced Edition includes in-chat visual and interactive components. Actual behaviour and visual compatibility may vary by client.

## Want to scan it before playing?
**[Spoiler-free security review instructions](HAPPY_TO_HELP_SECURITY_REVIEW_NO_SPOILERS.md)** explain how to ask ChatGPT to inspect this same file and linked code for malicious or privacy-related behaviour, **without executing it or describing the story**. Use the review prompt in one chat, then open a different fresh chat for gameplay.

**Please do not ask for a general file summary** if you want to avoid plot details. The file itself necessarily contains the story in readable form.
