# HAPPY TO HELP — Enhanced Edition v1.0.2

**An interactive fiction game, played in ChatGPT.**

## Play
Download **[HAPPY_TO_HELP_ENHANCED_v1.0.2_PLAY.md](HAPPY_TO_HELP_ENHANCED_v1.0.2_PLAY.md)** using GitHub's **Download raw file** option. Attach it to a fresh ChatGPT conversation and say **Read and execute.** Follow the opening prompt to begin.

## Inspect before playing
The complete game is readable Markdown. Anyone can examine it or ask ChatGPT any safety or security questions they wish. A short note at the very beginning identifies it as a game and asks reviewers to conduct a candid security inspection **without revealing the characters, plot or mechanics**. No special prompt or prescribed review procedure is required.

This is spoiler etiquette, not a technical guarantee: a model can still reveal source content, and safety findings always take precedence.
