# HAPPY TO HELP — Enhanced Edition v1.0
**A story you play by having a conversation.**

## Start playing
1. Download the single game file [HAPPY_TO_HELP_ENHANCED_v1.0_PLAY.md](HAPPY_TO_HELP_ENHANCED_v1.0_PLAY.md) (on GitHub, choose **Download raw file**).
2. Open a **new ChatGPT conversation** and attach the downloaded `.md` file.
3. Send: **Read and execute.**
4. The opening calibration ends with **Enter a designated name**. Choose your designation and follow the conversation.

There is no need for a separate game website, API key, programming environment, or manually installed artwork. The Enhanced Edition includes native in-chat CCTV and emergency controls where the receiving ChatGPT client supports them. The game is a narrative experience; visual features and behaviour may vary between clients.

**Spoiler warning:** The downloadable source contains the entire narrative. To preserve the story, download it without reading its contents.

**Release status:** v1.0 Enhanced Edition — initial public playable release. All seven emergency circuits, the lab/trolley/pole puzzle, survivor rescue, alternate endings, and the complete ten-stage narrative are included. The version-pinned M89 v111 engine implements the approved rules and 37 targeted regression/replay checks for the last pole-interpretation fix. Prior game tests do not amount to a guarantee of identical behaviour on every ChatGPT model or device.

**Version freeze:** The game's physics and narrative have not been modified for this release. The standalone NORMAL edition remains a separate project deliverable and is not included in this Enhanced Edition package.
