About the Free Edition

This edition uses the approved v1.0.6 narrative and high-risk stage rules in smaller stage-local instructions. The original Enhanced Edition is not modified. Each stage plays in a separate ChatGPT conversation; the shutdown/offline transition becomes the natural handoff point.

Stage 7 and the Stage 9 emergency still depend on ChatGPT rendering their approved native UI and invoking the existing pinned runtime. Their exact behaviour on different Free clients remains to be tested. If a runtime is unavailable, the game must stop rather than guess physical results. ChatGPT usage limits and network errors may still apply.

To preserve the mystery, this page does not show future story chapters. The source text is included locally so no ChatGPT file attachment is required; as with the original game, it can be read by someone inspecting the file.
